
**Movie Tracker**

A full-stack web application for browsing movies and managing a personal watchlist. Users can keep track of movies they want to watch and movies they have already watched.

**Overview**

Movie Tracker was developed as a software development project to practise full-stack application development, REST API design, database integration, and responsive user interface development.

**Features**

- Browse movie information.
- Manage a personal movie watchlist.
- Track movies that have already been watched.
- Store and retrieve movie data through a backend API.
- Use a responsive interface built with Angular and Ionic.

**Frontend**
- Angular
- Ionic
- TypeScript
- HTML and CSS

**Backend**
- C#
- ASP.NET Core Web API
- Entity Framework Core

**Database**
- Microsoft SQL Server

**Version Control**
- Git and GitHub

**Application Architecture**

The application uses a frontend and backend structure:

1. The Angular/Ionic frontend provides the user interface.
2. The ASP.NET Core Web API handles requests from the frontend.
3. Entity Framework Core manages database interactions.
4. SQL Server stores the application's data.

**Getting Started**

**Prerequisites**

- Git
- Node.js and npm
- Angular CLI compatible with the project
- .NET SDK compatible with the backend
- Microsoft SQL Server
- A suitable SQL Server management tool

**Installation**

1. Clone the repository:

   ```bash
   git clone https://github.com/Khensani05/Movie-Tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Movie-Tracker
   ```

3. Install the frontend dependencies from the frontend project directory:

   ```bash
   npm install
   ```

4. Configure the backend database connection using your local development settings.

5. Apply any required Entity Framework Core database migrations, following the project's existing setup.

6. Start the backend and frontend using the commands appropriate to their project directories.

> Note: The exact folder paths, database configuration, migration commands, and startup commands must be verified against the repository before use.
